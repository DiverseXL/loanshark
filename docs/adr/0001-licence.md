# ADR-0001: Licence

Status: Provisional
Context: The brief says MIT or Apache-2.0 if that remains the category requirement. The hackathon rules have not been seen.
Options: MIT; Apache-2.0.
Decision: Apache-2.0, provisionally. It matches the licence of QoreSeal and the QoreChain SDK and carries a patent grant.
Consequences: Dependencies must be licence-reviewed before submission (M7). Kyrve code is not copied.
Test required: Confirm the official requirement; run a dependency licence check in M7.
